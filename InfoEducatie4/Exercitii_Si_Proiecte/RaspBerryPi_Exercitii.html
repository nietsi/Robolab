Acasa RaspBerry Pi Proiecte

> RaspBerry Pi Exercitii

1. Ce tip de platformă de calcul este Raspberry Pi 4?

Single-board computer (SBC)
Placă video dedicată
Microcontroler simplu fără OS

2. Pe ce arhitectură se bazează procesorul Broadcom BCM2711?

x86_64 (Intel/AMD)
ARMv8-A (Cortex-A72)
PowerPC

3. Ce tip de memorie RAM utilizează Raspberry Pi 4?

DDR2 SDRAM
LPDDR4 SDRAM
GDDR6

4. Care este rezoluția maximă suportată de cele două porturi micro-HDMI?

4K (Ultra HD)
Doar 1080p (Full HD)
720p (HD Ready)

5. Ce îmbunătățire majoră aduce RPi 4 la nivel de magistrală USB/Ethernet?

Împart ambele aceeași bandă limitată
Utilizează un controler PCIe dedicat pentru USB 3.0
Nu mai suportă conexiune Ethernet

6. Ce tip de mufă este utilizată pentru alimentarea plăcii?

Micro-USB la 5V 1A
USB-C la 5V 3A
Mufă jack cilindrică de 12V

7. Ce limbaj de programare este frecvent utilizat datorită simplității și suportului?

Assembly
Pascal
Python
